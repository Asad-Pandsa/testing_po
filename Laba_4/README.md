# Лабораторная работа 4

## Классы эквивалентности

Для `score`: меньше 0, 0-49, 50-69, 70-89, 90-100, больше 100 и неправильный тип.

Для `attendance`: меньше 0, 0-59, 60-69, 70-79, 80-100, больше 100 и неправильный тип.

## Граничные значения

- `score`: 0, 49, 50, 69, 70, 89, 90, 100;
- `attendance`: 0, 59, 60, 69, 70, 79, 80, 100.

Также проверяются значения `-1` и `101`, а неправильные типы вызывают `TypeError`.

## Тесты

`test_student.py` использует `@pytest.mark.parametrize` для классов эквивалентности и граничных значений, а также `pytest.raises()` для проверки неправильных типов.

Запуск:

```powershell
python -m pytest -q
```
